# Pluvicto Genomic Biomarker Analysis

This repository contains analysis code aimed at identifying and validating genomic biomarkers predictive of response, resistance, and clinical outcomes for **Pluvicto** ($\text{}^{177}\text{Lu-PSMA-617}$) in prostate cancer.

---

## Overview

Pluvicto is an FDA-approved PSMA-targeted radioligand therapy for patients with metastatic castration-resistant prostate cancer (mCRPC). While effective, response rates vary significantly among patients. This project leverages genomic profiling (e.g.,SNVs/CNV, clonal evolution) to discover molecular predictors that can help optimize patient selection and treatment strategies.

---

## Key Features

* **Project overview:** Genomic landscape plotting, cohort demographics, Fishplots for clonal evolution, PSA50 kinetics, OS analysis
